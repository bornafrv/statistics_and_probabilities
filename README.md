# 📊 Statistics & Probabilities – University of Tehran Projects

This repository contains hands-on projects related to **Probability and Statistics**, implemented as part of coursework at the **University of Tehran**.  
Each folder explores key statistical concepts using real datasets, simulations, and visualizations — combining theory with practice through Python and Jupyter Notebooks.

---

## 📁 Project Structure

| Folder Name                                             | Description                                                                 |
|----------------------------------------------------------|-----------------------------------------------------------------------------|
| 📘 **Bayes Law and Text Preprocessing**                  | Text classification using Naive Bayes & Persian NLP with `hazm`             |
| 🧮 **Binomial, Bernoulli, Normal and Poisson Distributions** | Simulations and comparisons of core distributions and their approximations |
| 🧠 **Conditional Distribution, Moment Generator & Bayesian Estimation** | Real-world datasets + symbolic/empirical estimation techniques              |
| 📈 **Mean Squared Error, Regression and Central Limit Theorem** | Regression, autoencoders (MSE), and CLT demos using visual data             |

---

## 📦 Core Concepts Covered

- **Bayes' Theorem**
- **Naive Bayes Classification**
- **Discrete & Continuous Distributions**
- **Monte Carlo Simulations**
- **Regression & R²**
- **Central Limit Theorem (CLT)**
- **Moment Generating Functions (MGFs)**
- **Bayesian Updating**
- **Normality Tests** (Shapiro-Wilk, Q-Q plots)
