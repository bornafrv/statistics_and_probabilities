# 📊 Probability & Statistics Project – University of Tehran

## 📌 Project Overview
This project explores essential statistical concepts, including **Mean Squared Error (MSE)**, **Regression & Least Squares**, and the **Central Limit Theorem (CLT)**.  
Using Python and real-world datasets, the project connects theoretical understanding with practical implementation through simulations, statistical testing, and graphical analysis.

---

## 🧱 Key Components

### 1️⃣ Mean Squared Error (MSE) – Image Reconstruction

- Evaluates the performance of an **autoencoder model** on the **MNIST dataset**
- Calculates **MSE** between original and reconstructed images
- Assesses the distribution of MSE values using:
  - 📊 Histogram plots
  - 📈 Kolmogorov-Smirnov (K-S) test

---

### 2️⃣ Regression & Least Squares

- Fits a linear model to data using **least squares regression**
- Analyzes:
  - 🔍 **Outlier detection**
  - 📌 **Leverage points** and their effect on the regression line
- Computes:
  - 📈 **R² (coefficient of determination)**
  - Robust methods to handle distortion by extreme values
- Visualizes:
  - Regression lines with and without outliers

---

### 3️⃣ Central Limit Theorem (CLT) & Sampling

- Demonstrates CLT using **sampling simulations**
- Dataset: **FIFA 2020** player statistics
- Techniques and tools:
  - 🔁 Random sampling from different distributions (e.g., Poisson)
  - 📈 Q-Q plots to compare sample distribution vs. normal distribution
  - 🧪 **Shapiro-Wilk** normality test

---

## 📈 Deliverables

- ✅ **Python Code** for:
  - MSE computation on image data
  - Regression modeling and outlier analysis
  - CLT simulation and statistical testing

- 📊 **Graphical Analysis**:
  - Histograms, Q-Q plots, and regression visualizations

- 🧠 **Statistical Interpretation**:
  - Normality tests, hypothesis validation, and theoretical vs. empirical analysis
